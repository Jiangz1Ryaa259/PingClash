# PingClash 使い方ガイド

このガイドでは、PingClash 0.2.3の主な機能、よく使う操作、設定について説明します。PingClashはAndroid 10以降で動作し、AndroidのVPN機能を使って通信を振り分けます。root化は必要ありません。プロキシのサブスクリプションや設定ファイルはご自身で用意してください。そこに含まれるリンク、パスワード、鍵は大切に保管してください。

## 1. インストールと初めての接続

APKはプロジェクトのGitHub Releasesからダウンロードします。arm64-v8a向けのビルドで、最近のAndroidスマートフォンならほぼすべてで動作します。インストールすると、画面下にホーム、プロキシ、プロファイル、設定のタブが表示されます。PingClashのアカウントはないので、サインインは不要です。

### 初期設定ガイド

初めてアプリを開くと、7つのステップからなる初期設定ガイドが表示されます。

1. **言語を選ぶ**：アプリで使う言語（現在は简体中文、English、日本語）を選びます。端末の言語が自動で使われることはありません。選んだ言語はすぐに反映され、あとから「設定 → 言語と外観」で変更できます。
2. **ようこそと利用規約**：PingClashは独自のサーバー、サブスクリプション、アカウントを持たないクライアントであることを説明し、利用規約を表示します。「同意する」をタップすると先に進みます。同意しない場合は「終了」をタップしてください。アプリが閉じ、次回また利用規約が表示されます。
3. **使い方**：インポート、接続、ノード選択の流れを簡単に紹介します。アプリに内蔵されたこのガイドも読めます（ネットワーク不要）。
4. **プロファイル**：サブスクリプションをインポートするか、別の端末のバックアップを復元します。あとで行うこともできます。
5. **お好みで**：よく使うサービスについて、プロキシ、ダイレクト、デフォルトのいずれかを選びます。詳しくは後述の「サービス別ルーティング」をご覧ください。国や地域ごとのほかのサービスは「設定 → サービス別ルーティング」にあります。
6. **ブロック**：広告、または広告とトラッキングをブロックするかどうかを選びます。詳しくは後述の「広告ブロック」をご覧ください。
7. **準備完了**：設定内容を確認してホームに移動します。使えるプロファイルがあれば、そのまま接続することもできます。

言語と利用規約より後のステップはスキップできます。画面上部の「初期設定をスキップ」を押すと、すぐにホームに移動します。スキップすると、「設定 → 初期設定ガイド」からいつでも再開できることがホームに表示されます。あとで利用規約が変更された場合は、ガイド全体を繰り返すことなく、利用規約だけをもう一度確認していただきます。利用規約とこのガイドは「設定 → アプリ情報とライセンス」からも開けます。

利用規約は全14項です。ソフトウェアの概要とライセンス、サーバーやサブスクリプションを提供しないこと、法令の遵守、データが端末内に保存されること、アプリの接続先、VPNとその他の権限、インポートする設定のリスク、サービス別ルーティングと広告ブロックの限界、動作の保証、第三者のコンポーネント、責任の制限、規約の変更、フィードバック、言語について定めています。英語版が正本で、アプリに表示されている版が適用されます。

接続するには、「プロファイル」を開いて右下の追加ボタンをタップし、インポート方法を選びます。インポートしたらプロファイルのカードをタップして選択し、「プロキシ」でノードまたはグループのメンバーを選びます。ホームに戻ってモードを選び、バッジをタップします。AndroidのVPN許可画面が表示されるので、許可するとステータスバーにVPNのアイコンが表示され、通知にサービスの状態が表示されます。

システムのVPN許可とサブスクリプションのインポートは別のものです。インポートは設定を保存するだけで、VPNの許可の代わりにはなりません。AndroidのVPN機能を同時に使えるのは通常1つのアプリだけなので、別のVPNアプリを起動すると、PingClashの接続が切れることがあります。初めて接続するときは、有効期限やお知らせを表示するためのダミーノードではなく、実際のプロキシノードを選んでいるか確認してください。

## 2. ホームと接続

### バッジ

バッジの接続ボタンをタップすると、VPNを開始または停止できます。バッジは接続状態に合わせて裏返ります。長押しでのドラッグはカードを動かすだけで、ノードやモードは変わりません。指を離すとカードは元の位置に揺れて戻ります。動きの少ない表示がお好みの場合は「視覚効果を減らす」をオンにしてください。

別のアプリに切り替えてもVPNは切断されません。アプリに戻ったら、バッジ、システムのVPN設定、サービスの通知で接続状態を確認できます。「最近使ったアプリ」のカードはアプリの画面で、通知はサービスを表しており、この2つは別のものです。プロキシを止めるには、接続ボタンまたは通知の停止ボタンを使ってください。

### ルール、グローバル、ダイレクト

| モード | 動作 |
| --- | --- |
| ルール | 現在のプロファイルのルールと端末で追加したルールに従って、グループと接続先を選びます。普段使いに向いています。 |
| グローバル | すべての通信をメインプロキシ経由にします。全部を同じ経路にしたいときに使います。 |
| ダイレクト | 通信を直接送信します。プロキシノードは使いません。 |

ホームのカード上部にあるダイヤルでモードを切り替えます。ダイヤルにはルール、グローバル、ダイレクトが繰り返し並んでいます。青い線の下にある太字が現在のモードで、その左右に隣のモードが薄く表示されます。

- **左右をタップ**すると、その側のモードに切り替わります。続けてタップすると順に進みます。
- **横にドラッグまたはフリック**すると、ダイヤルが指に合わせて動きます。指を離すと自然に減速し、最寄りのモードを少し通り過ぎてから戻ります。モードを通過するたびに軽い振動があり、止まるとカチッと振動します。
- モードが切り替わるのはダイヤルが止まったときだけなので、ドラッグ中にルーティングが何度も再読み込みされることはありません。「視覚効果を減らす」がオンのときは、惰性や跳ね返りなしで次のモードに移動します。

ダイヤルの下には、現在のプロファイル、ノード、通信の出口（地域とネットワーク）が表示され、接続中はリアルタイムの速度、未接続時はデータ残量が表示されます。この部分をタップすると、通信量、接続時間、遅延、動作状態を確認できます。プロファイルを変更するには「プロファイル」、ノードやグループのメンバーを変更するには「プロキシ」を開きます。モード、プロファイル、ノードはそれぞれ独立して選べます。

### ウェブサイトの接続状況

ホームのカード下部には、よく使うウェブサイトの簡易チェックがあります（縦向きでは同じカード内に表示されます）。サイトをタップするとそのサイトをテストし、稲妻ボタンをタップすると表示中のサイトをまとめてテストします。矢印からほかのサイトも選べます。テストの通信が発生するのは自分で開始したときだけで、一覧を開いてもどこかにサインインすることはありません。

このチェックでは、端末の実際の経路を使って、今のネットワークからサイトに届くかどうかを確かめます。ノードのURLテストとは別のものです。VPNがオフのときは現在のネットワークを使い、オンのときはモードとルールに従います。検証済みのHTTPS接続でサイトが応答すれば、到達可能として応答時間を表示します。サインインやCAPTCHAのページへのリダイレクト、403や429などのステータスも到達可能に含まれます。DNSエラー、タイムアウト、接続の拒否やリセット、証明書の問題は到達不可になります。ChatGPT、Claude、Geminiが「お住まいの地域では利用できません」というページを返した場合や、サイトが451を返した場合は「アクセス制限あり」と表示します。1回のチェックで、アカウントやサイトのすべての機能が使えると確認できるわけではありません。

古い結果は、ネットワーク、接続状態、プロファイルが変わると更新または消去されます。ページは開けるのにチェックでは問題が出る場合は、もう一度テストしてブラウザと比べてみてください。テストのためにHTTPSの証明書検証をオフにしないでください。

### IP情報

ホームのカードの概要には、現在のIPの国または地域とネットワークが表示されます。タップすると、IPアドレス、組織、ASN、確認日時を確認できます。接続中は、この通信にルールが選んだ経路（ダイレクト、またはグループ、ノード、プロトコル）も表示されます。

確認は端末の実際の経路で行います。VPNがオンのときは現在のモードとルールに従い、オフのときは端末自身のネットワークを使うので、今ウェブサイトから見えているアドレスがわかります。接続、切断、モード・プロファイル・メインプロキシの変更のあとに自動で再確認され、詳細画面の「更新」からも確認できます。アドレスはCloudflareから取得します。国や地域以外のネットワーク情報はアプリに内蔵されたデータによるもので、結果はメモリ上にのみ保持されます。

## 3. プロファイルの追加と管理

### インポート方法

「プロファイル」で右下の **+** をタップすると、URL、クリップボード、設定の貼り付け、ファイル、ZIPバンドル、QRコード画像、QRコードの撮影から選べます。インポートは1つの画面で完結します。内容を入力し、取得元を確認して「ダウンロードしてインポート」をタップしてください。ダウンロード中でも、戻ってキャンセルできます。

- **URL**：HTTPSのサブスクリプションアドレスを貼り付けます。リンクは初期状態で隠され、ダウンロード元のホストが下に表示されます。名前は空欄のままでもサーバーの情報から自動で入り、編集もできます。User-Agentは「詳細設定」にあります。
- **クリップボード**：インポートするものを選んだときだけ読み取り、確定の前に内容を確認できます。リンクをコピーしただけでダウンロードや有効化が行われることはありません。
- **テキスト**：Clash YAML、設定JSON、対応するノードURIの一覧を貼り付けます。Base64でエンコードされたサブスクリプションの内容もインポートできます。
- **ファイル**：Androidのファイル選択を使うので、ストレージ全体へのアクセス権は必要ありません。
- **QRコード**：画像からオフラインで読み取るか、システムのカメラで撮影します。鮮明な元画像を使い、光の反射や見切れに注意してください。
- **ZIPバンドル**：ローカルのプロバイダーファイルを含む設定向けです。ファイルはバンドル内の相対パスで参照します。

ウェブページから`clash://install-config?url=`が開かれた場合は、まず取得元のホストを確認してインポートを確定し、プロファイルを有効にするかどうかは別に選びます。リンクに含まれる名前は表示用のものです。取得元にはHTTPSを使ってください。トークン付きのサブスクリプションリンクはパスワードと同じように扱い、公開のコメントやスクリーンショットに載せないでください。

### ZIPバンドルとプロバイダー

バンドルのルートにはconfig.yaml、config.yml、config.jsonのいずれか1つを置きます。ほかのファイルは、設定内のプロバイダーの相対パス（例：providers/nodes.yaml）に合わせて配置します。ファイル名とパスは完全に一致させてください。絶対パスや親ディレクトリの参照は使えません。

Mihomoの設定にはproxy-providersとrule-providersを含めることができます。アプリはその取得元と更新設定を読み取り、アプリ専用の領域にダウンロードして、グループにメンバーを割り当て、ルールを元の順序で処理します。対応する取得元の形式、内容の形式、上書きは、インポート機能と現在のコアによって異なります。ルールプロバイダーは内容で判別するので、.txtや.listとして公開されたYAMLリストも使えます。1つのプロファイルに入るのは最大でノード5,000、グループ512、ルール50,000で、サブスクリプションのダウンロードとインポートは8 MiBまでです。超えた分はスキップされ、件数が詳細に表示されます。取得元のエラーは詳細にプロバイダーの番号で表示されるので、設定内の該当箇所を探せます。

設定で地域やASNのカテゴリを使っている場合は、対応するルールデータが実行時に使われます。設定内のグループ名、取得元名、参照はそのまま保ってください。特に、グループ名を変えるときは、それを指しているルールも一緒に変更してください。ファイルを使うプロバイダーは、ファイルまたはZIPで内容をインポートしてください。

### プロファイルのカード

プロファイルは縦に並びます。カードのどこかをタップすると選択され、選択中のカードは強調表示されます。カードの塗りはデータ残量を表し、通信量が変わったときや選択したときに変化します。データ残量はサブスクリプションのサービスが返すレスポンスヘッダーから取得します。サービスから情報がない場合に、無制限として扱うことはありません。

カード右上のメニューには、更新、名前の変更、サブスクリプションリンクのコピー、詳細、エクスポート、削除があります。詳細では、使用量、総量、有効期限、ノードとグループ、取得元の状態、インポート結果を確認できます。コピーしたものはほかのアプリからクリップボード経由で読まれる可能性があります。共有する前に、本当に共有してよい内容か確認してください。

### 更新、名前、User-Agent

サブスクリプションを更新すると取得元から再取得しますが、失敗したときのために現在の有効な設定は保持されます。自動更新の間隔は「設定 → 自動化」で選べます（初期設定は毎日）。プロファイルの名前は自由に変更でき、サーバー側のアカウントには影響しません。サービスによってはUser-Agentによって返す形式が変わるので、必要に応じて、プロバイダーが指定する値をインポート画面またはプロファイルの設定に入力してください。User-Agentはリクエストの識別に使うもので、認証情報ではありません。

データ量と有効期限は、サーバーのsubscription-userinfoから取得します。使用量は通常アップロードとダウンロードの合計で、日付は端末のタイムゾーンで表示されます。アプリの通信量の表示とプロバイダーの課金は一致しないことがあります。料金、リセット周期、更新手続きはプロバイダーによって異なります。更新後に新しいデータ量を確認してください。

### エクスポートと削除

エクスポートは、自分の設定の保管や移行に使うものです。完全な設定にはアカウントの認証情報、サーバー情報、サブスクリプションリンクが含まれることがあるので、安全な場所に保管してください。問題の報告には、機密情報を除いた診断レポートを使います。完全な設定をレポートとして公開しないでください。プロファイルを削除するとアプリから消えます。アプリをアンインストールしたりデータを消去したりしても、端末内のプロファイルは消えます。

## 4. プロキシ、グループ、遅延

「プロキシ」では、サブスクリプションのグループの順序、名前、メンバー構成がそのまま表示されます。左右にスワイプしてグループを切り替え、ノードをタップして選択します。入れ子のグループはさらに開けます。自動選択やフォールバックなどのグループは設定どおりに動作します。グループ名はプロトコルではなく、特定のサーバーアドレスを表すものでもありません。

右上のメニューでは、2列のコンパクト表示と1列表示を切り替え、名前順や遅延順に並べ替えられます。検索では現在のプロファイルのメンバーを探せます。プロトコル名はサブタイトルに表示され、長い名前や大きな文字にもレイアウトが対応します。ページを切り替えたり診断から戻ったりしても、できるだけ元の位置を保ちます。

### URLによる遅延テスト

稲妻ボタンを押すと、MihomoによるURLテストが始まり、ノード経由で対象に届くまでの時間を測ります。ノードのテストはこのアプリのVPNがオフでも実行できます。テストするのはノードの接続能力であり、端末のすべてのアプリがVPNを通っているかどうかではないためです。別のVPNを使っている場合は、そのオーバーヘッドも経路に含まれることがあります。

一括テストでは、グループのノードを展開して重複を除き、同時実行数を抑えて実行し、結果が出たものから順に表示します。実行中のアイコンをもう一度タップするとキャンセルできます。一括テスト中でもほかのノードを選べます。結果は残るので、ページの切り替え、アプリからの移動、VPNの接続や切断で完了済みの結果が消えることはありません。プロファイルを更新すると、削除や変更があったノードの結果だけが消え、テスト対象、タイムアウト、DNSを変更するとすべて消えます。接続や切断を行うと、実行中のテストは止まります。数値はネットワーク、対象サイト、最初のハンドシェイクに左右されるので、同じ対象とタイムアウトで比べてください。

遅延の色は目安です。緑は低遅延、黄色は中程度で、高遅延と失敗にはそれぞれ別の表示があります。数値はそのテストの結果であり、長期的な品質を示すものではありません。結果なし、テスト中、タイムアウト、有効な遅延はそれぞれ別の状態で、失敗をそれらしい数値で表示することはありません。

### TCPとノードの詳細

ノードを長押しすると詳細が開き、URLテスト、TCPテスト、そのノードの診断を実行できます。TCPテストはノードのホストとポートに接続し、ノードのサーバーに届くかどうかを確認します。URLテストはプロキシプロトコルを通って対象まで届くかを確認するので、経路のより多くの部分がわかります。TCPに接続できても、プロキシの認証や対象サイトへの接続が成功するとは限りません。

UDPプロトコルでは、TCPのテスト結果は失敗ではなく「対象外」と表示されます。このアプリ自身のVPN使用中は、ノードへの確認に保護されたソケットを使って実ネットワークに直接接続するので、トンネルに戻ってループすることはありません。別のVPNを使っていると、その経路の影響で一部の直接テストが制限されます。ノードのURLテストが終わっていれば、一覧全体の完了を待たずにそのノードの診断を確認できます。

## 5. 診断、お知らせ、接続

### 接続診断

診断はノードの詳細または設定から開きます。結果は、ネットワーク、ノードのDNS、TCP、TLS、プロキシの経路の順に表示されます。プロトコルが使わないステップは「スキップ」と表示されます。診断がインターネットをスキャンすることはなく、失敗の原因を調べるために証明書の検証を回避することもありません。

まず失敗した段階を確認してください。DNSは名前解決、TCPはノードへの接続、TLSは証明書、ホスト名、ハンドシェイクに関わります。プロキシの経路には、さらにプロトコルの認証と対象への到達も関わります。タイムアウト、リセット、接続拒否、証明書エラーはそれぞれ別のもので、エラーが1つ出ただけでネットワークが攻撃を受けているとは言えません。同じ端末でWi-Fiとモバイルデータを切り替えて、もう一度試して比べてみてください。

診断画面の下にある**ドメインまたはIPを手動で確認**を押すと、直接チェックが開きます。サーバーのドメインまたはIPとポートを入力します。TLSハンドシェイクとSNI、IPv4またはIPv6も指定できます。このチェックはノードを経由しません。常に端末の実際のネットワーク（Wi-Fiまたはモバイルデータ）を使い、VPNがオンのときはトンネルを迂回します。わかるのは、この端末からそのアドレスを直接名前解決して接続できるかどうかだけで、プロキシが使えるかどうかはわかりません。

### お知らせと警告

黄色のお知らせは右上に表示され、カウントダウンのあとに自動で消えます。赤い警告はスワイプで消すか詳細を開くまで残り、詳細では段階、原因、対処方法を確認できます。インポートに失敗したら、まず取得元または項目の説明を確認してください。サブスクリプション全体を誰かに送る必要はありません。

証明書の扱いは設定に従います。検証をスキップする設定では、サーバーの身元を確実に確認できません。提供元を把握し、プロバイダーの証明書設定を確認してください。端末の時刻のずれ、SNIの不一致、信頼されていない証明書はいずれもTLSに影響します。通常のエラーメッセージはスクリーンショットを撮れますが、認証情報を直接表示する画面には別途スクリーンショットの保護があります。

### 接続

「設定 → 接続」でセッションを確認できます。VPNがオフのときや接続がないときは、一覧の代わりに状態カードが表示されます。対応する表示オプションをオンにすると、宛先、ネットワークの種類、一致したルールの種類、実際の接続経路、接続時間、通信量を確認できます。宛先の表示は別のオプションなので、必要なときにオンにしてください。閲覧内容が推測されることがあるので、共有する前に確認してください。

接続を左にスワイプすると削除ボタンが表示され、そのままスワイプを続けると直接閉じられます。閉じるのは現在の接続だけで、ノードやサブスクリプションは削除されません。ネットワークを使っているアプリやウェブページは、すぐに新しい接続を開くことがあります。ノードを変更したときに既存の接続にすぐ反映されるかどうかは、接続と経路によって異なります。

### レポートの共有

診断レポートは端末内で作成されます。共有する前にプレビューし、機密情報を手で書き足していないか確認してください。フィードバックには、アプリのバージョン、Androidのバージョン、操作手順、失敗した段階、確認済みのレポートがあれば通常は十分です。アカウントのパスワード、UUID、完全なサブスクリプションアドレス、端末の識別情報は伝えないでください。クラッシュレポートも自分で確認して共有するもので、自動でアップロードされることはありません。

## 6. DNS、ルーティング、ネットワーク設定

### DNS

サブスクリプション本来のDNSの動作を保つには、「設定のDNSを使用」をオンにします。手動で設定する場合は、アプリのDNSモードと暗号化DNSのアドレスを選びます。DNS over HTTPSにはHTTPSのアドレス、DNS over TCPには対応するサーバー設定を使います。変更する前に元の値を控えておいてください。また、ノード、DNS、ルールを同時に変更すると、どれが影響したのかわからなくなるので避けてください。

Fake-IP、ドメインルール、スニッフィングなどの動作は、設定とコアの動作によって異なります。DNSのアドレスはプロキシのアドレスではなく、DNSのチェックが成功してもサイトに接続できるとは限りません。ブラウザやシステムで独自のプライベートDNSがオンになっている場合は、最終的な名前解決の経路を考えるときにそれも考慮してください。

### アプリごとのVPN

**すべてのアプリ**では、VPNの経路の対象となるすべてのアプリがVPNを通ります。**選択したアプリを除外**では、選択したアプリがVPNを通りません。**選択したアプリのみ**では、選択したアプリだけがVPNを通ります。一覧では、検索と、選択済みやシステムアプリの絞り込みができます。チェックを入れる前にアプリ名とパッケージ名を確認し、システムコンポーネントには注意してください。

「アプリごとのVPN」はAndroidのVPNを通るアプリを決めるもので、モードはコアに届いたあとの接続経路を決めるものです。どちらも通信に影響します。システムのVPNを再構築する必要がある設定では、案内が出たら切断して再接続してください。ロックダウンモードを使っている場合は、除外したアプリとシステムのブロックの組み合わせを確認してください。

### ルーティングルールとローカルネットワーク

サブスクリプションのルールを保ったまま、端末でルールを追加できます。ルールの種類、一致条件、接続先、ルールプロバイダーの参照は対応している必要があり、順序によって一致の結果が変わります。ルールを書いたら保存して、チェック結果を確認してください。実行中のルール番号は、設定ファイルの行番号ではありません。

「設定 → ネットワークと接続」の「ローカルネットワーク」で、LANの通信の扱いを決めます。ルーター、プリンター、NASに接続するには、「LANをプロキシ」「LANは直接接続」「LANをブロック」から選びます。必要な理由がわからない場合は、LANでの待ち受けを開放しないでください。アプリの制御機能はアクセスが制限された端末内の接続を使うので、制御ポートをほかの端末に公開する必要はありません。

### サービス別ルーティング

「設定 → サービス別ルーティング」には、国や地域ごとによく使うサービスが並んでいます。アメリカ、イギリス、日本、韓国、中国 – 香港、中国 – 台湾、中国 – 本土のほか、世界共通のAI、ゲーム、仕事とSNSの3つのグループがあります。各サービスで次のいずれかを選べます。

| 選択肢 | 動作 |
| --- | --- |
| プロキシ | メインプロキシ（現在のプロファイルのメイングループまたは選択中のノード）か、プロファイルから選んだグループを使います。 |
| ダイレクト | プロキシを通しません。 |
| デフォルト | ルールを追加せず、サブスクリプションのルールに任せます。 |

プロキシを選んだときに現在のプロファイルにグループがあれば、サービス名の下に使用するプロキシが表示されます。最初は「メインプロキシ」です。タップするとプロファイルのグループを選べるので、たとえばNetflixを日本のグループ経由にできます。そのグループがないプロファイルに切り替えると、そのサービスは一時的にメインプロキシを使い、その旨が表示されます。元のプロファイルに戻すと、再びそのグループを使います。

これらの選択はサブスクリプションではなくPingClashに保存されます。サブスクリプションを切り替えたり更新したりしても残り、設定と一緒にバックアップされます。適用されるのはルールモードのときで、順序はカスタムルールの後、サブスクリプションのルールの前です。接続中でも変更はすぐに反映され、切断する必要はありません。広告ブロックと上部の地域タブは固定され、下のサービス一覧だけがスクロールします。右上の**すべて解除**を押すと、すべてのサービスがデフォルトに戻ります。広告ブロックは変わりません。

サービスのドメインはアプリに内蔵されたルールデータ（GeoSite）から取得するので、ルールのダウンロードはありません。あるサービスが別のサービスに含まれる場合（YouTubeはGoogleの一部）は範囲の狭いほうが先に適用されるので、「Googleはプロキシ、YouTubeはダイレクト」のような設定もできます。プロキシを選んでも、メインプロキシを使うだけです。その地域のコンテンツを視聴できるかどうかは、ノードの所在地とサービス側の制限によって決まります。

### 広告ブロック

「設定 → サービス別ルーティング」上部の**広告ブロック**では、オフ、広告、広告・追跡から選べます。内蔵のルールデータにある既知のドメインをブロックし、ルールモードのときに適用されます。一部のサイトやアプリが正しく動かなくなることがあります。その場合はここでオフにしてください。

### 接続の設定

「ネットワークと接続」には、自動再接続、IPv6、UDP、MTU、接続タイムアウト、テスト対象、同時テスト数などの設定があります。ほとんどの場合は初期設定のままで問題ありません。MTUはパケットのサイズに関わり、大きすぎても小さすぎても動作が変わることがあります。同時テスト数を増やしすぎると、端末とノードに一時的に負荷がかかります。比較できるように、設定は1つずつ変更して結果を確認してください。

## 7. 標準ターミナル

ターミナルはAndroidの`sh`です。Windows PowerShellでも完全なLinuxディストリビューションでもありません。PingClashのアプリUIDと権限で動作し、端末にもともとあるコマンド、ディレクトリ、ネットワークを使います。PTYに対応しているので、通常のキーボード入力、色付きの出力、パイプ、リダイレクト、対話型の入力が使えます。

初めて開くときは権限についての説明をお読みください。ターミナルの領域をタップするとキーボードが開き、Enterで実行します。Ctrl+Cで実行中のコマンドを中断し、exitでシェルを終了します。ターミナルの内容はコピーやスクリーンショットができます。共有する前に、入力したサブスクリプションアドレスやパスワードがコマンドや出力に含まれていないか確認してください。

次のコマンドで、使えるものを確認できます。結果はご自身で確認してください。

```sh
pwd
id
uname -a
ls -la
printf '\033[36mPingClash terminal\033[0m\n'
printf 'one\ntwo\n' | wc -l
command -v ping
command -v curl
```

使えるツールがわかったら、端末が対応しているネットワークコマンドを使えます。次の例は公開ドメインを使うので、サブスクリプションの認証情報は必要ありません。

```sh
ping -c 3 example.com
```

Androidのシステムによっては、特定のコマンドがなかったり、ICMP、rawソケット、システムディレクトリが制限されていたりします。コマンドの有無は`command -v`で確認できます。ターミナルが追加のソフトウェアをインストールすることはなく、アプリの権限でroot権限を得ることもありません。システムのコマンドは実際の経路に従うので、選択したノードを必ず通るわけではありません。

内容を理解していないリモートスクリプトは実行しないでください。ターミナルはアプリ自身のファイルにアクセスでき、リダイレクトするとファイルが残ります。アプリがコマンド履歴を保存しなくても、コマンド自体が何かを書き込むことはあります。環境変数、ファイルの内容、認証情報付きのURLを公開のスクリーンショットに写さないようにしてください。

## 8. 外観、背景、端末内のプライバシー

### 外観

「言語と外観」では、简体中文、English、日本語、システムの言語から選べます。背景は、海と波、流れる雲、単色の背景、自分の画像から選べ、用意された色やカスタムカラーも編集できます。画像を使う場合、「全体に表示」ではピンチとドラッグで画面を覆う部分を選び、「全体を収める」では選んだ部分全体を表示して、残りを画像の端の色または選んだ色で埋めます。色の選択には、グリッド、スペクトル、スライダーがあります。画像は端末内で再エンコードして保存され、元のメタデータは残りません。ライトとダークの選択肢は、現在の背景が対応しているものだけが表示されます。背景の上に直接表示されるタイトルやラベルは、自分の画像の場合も含め、読みやすい色に変わります。「視覚効果を減らす」と「透明度を下げる」で、アニメーションやガラスの表現を控えめにできます。

ガラスのナビゲーションは、タップとドラッグで切り替えられます。バッジの長押しドラッグは、ページの切り替えとは別の操作です。動作の詳しい情報はホームの詳細パネルで確認でき、表示オプションで速度、通信量、サービス、メモリの表示を選べます。ステータス通知の速度表示には別の設定があります。

### 横向きとタブレット

横向きでは、画面下のナビゲーションが左側のすりガラスのサイドバーに変わります。開いているときはアプリ名、ページ、接続状態が表示され、左上のボタンでアイコンだけの表示に折りたためます。この状態は記憶されます。初期状態は、タブレットでは開いた状態、横向きのスマートフォンでは折りたたんだ状態です。タブレットの縦向きでは、ナビゲーションバーはスマートフォンと同じ比率で中央に表示され、設定とプロファイルは読みやすい幅に保たれ、プロキシは画面に合わせて列が増えます。

### バックグラウンドと再接続

自動再接続は、Wi-Fiとモバイルデータの切り替えに対応します。VPNの通知を表示したままにし、システムで通知を許可してください。通知のタイトルには現在のモードが表示されます。電池の管理でバックグラウンドの動作が制限される場合は、システムのアプリ情報で電池の最適化とバックグラウンドの権限を調整してください。メニューの名前はメーカーによって異なります。

AndroidのVPN設定にある「常時オンのVPN」はサービスを動かし続け、「VPN なしの接続をブロック」はトンネル外の通信をすべて遮断します。オンにしたら、ブラウザやよく使うアプリが動くことを確認してください。「最近使ったアプリ」からカードを消しても、VPNサービスは止まりません。

### 自動化とショートカット

クイック設定にPingClashのタイルを、ホーム画面にウィジェットを追加すると、アプリを開かずに接続や切断ができます。ウィジェットには現在の速度も表示されます。初回の接続ではアプリ内でVPNを許可する必要がありますが、その後はアプリを開かなくてもタイルとウィジェットを使えます。

「設定 → 自動化」でできること：

- 端末の起動時に接続（初期設定はオフ）。
- サブスクリプションの更新間隔：オフ、6時間または12時間ごと、毎日（初期設定）、2日または3日ごと、毎週。更新はネットワークがあるときにバックグラウンドでHTTPSのみで行い、ダウンロードや確認に失敗しても現在の設定はそのまま残ります。
- ネットワークに応じて接続（初期設定はオフ）：信頼できるWi-Fiでは切断し、それ以外のネットワークでは接続します。動作するのはネットワークが変わったときだけです。AndroidがWi-Fi名を提供するのは位置情報の権限がある場合のみで、アプリを閉じていても動作させるには「常に許可」を選ぶ必要があります。

「設定 → プライバシーとバックアップ」のバックアップでは、設定を選んだファイルに保存します。初期状態では、サブスクリプションリンク、ノードのパスワード、使用量は含まれません。**プロファイルを含める**をオンにすると、ファイルに認証情報が含まれるので、安全に保管してください。復元すると現在の設定が置き換えられ、バックアップにあって端末にないプロファイルが追加されます。サブスクリプションは再度ダウンロードされます。

### データと共有

プロファイルと設定は、Android KeystoreとAES-GCMで暗号化して端末に保存され、システムのクラウドバックアップと移行は無効になっています。広告、テレメトリ、自動のクラッシュレポートはありません。サブスクリプションの取得、プロバイダーの更新、DNS、遅延テスト、プロキシ接続では、機能に必要な範囲で、設定または選択したサービスに接続します。

暗号化された保存領域でも、コピーやエクスポートした平文は保護できず、画面ロックの代わりにもなりません。端末を変更する前に「プライバシーとバックアップ」でバックアップしてください。アンインストール、データの消去、システムの鍵の変更によって、端末内のデータを復元できなくなることがあります。サブスクリプション、秘密鍵、完全なログを公開リポジトリにコミットしないでください。

「アプリ情報とライセンス」では、アプリのバージョン、Mihomoのバージョン、オープンソースライセンスを確認できます。問題を報告するときはこれらのバージョンがあれば十分で、個人情報は必要ありません。機能についてはこのガイドを、プロジェクトとソースコードについては[README](../README.md)をご覧ください。
