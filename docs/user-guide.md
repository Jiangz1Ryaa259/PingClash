# PingClash 使用指南

本指南介绍 PingClash 0.2.3 的主要功能、常用操作与设置。应用支持 Android 10 及以上系统，使用 Android VPN 接口接管流量，不需要 Root。请准备自己的代理订阅或配置文件，并妥善保管其中的链接、密码和密钥。

## 1. 安装与首次连接

从项目的 GitHub Releases 下载 APK，适用于 arm64-v8a 设备（目前的 Android 手机基本都是）。安装后，底部导航包含首页、代理、配置和设置。首次打开时不需要登录 PingClash 账号。

### 设置向导

第一次打开时，应用会显示设置向导，共七步：

1. **选择语言**：选择应用使用的语言（目前为简体中文、English 和日本語；本指南会跟随所选语言）。应用不会自动沿用系统语言，选择后立即生效，之后也可以在「设置 → 语言与外观」中更改。
2. **欢迎与用户协议**：说明 PingClash 是不提供服务器、订阅或账号的客户端，并展示用户协议。点「同意」继续；不同意请点「退出」，应用会关闭，下次打开时仍会先显示协议。
3. **使用方法**：简要说明导入、连接和选择节点，并可阅读应用内置的完整使用指南（不需要联网）。
4. **你的配置**：导入订阅、恢复另一台手机的备份，或稍后再做。
5. **如你所愿**：为几项常用服务选择「代理」「直连」或「默认」，详见下文「服务分流」。更多国家和地区的服务在「设置 → 服务分流」中。
6. **拦截**：选择是否拦截广告，或拦截广告与跟踪，详见下文「广告拦截」。
7. **准备就绪**：查看设置结果，进入首页；已有可用配置时也可以立即连接。

语言和协议之后的每一步都可以跳过，顶部的「跳过设置」可直接进入首页。跳过后首页会提示：可以随时在「设置 → 设置向导」中完成设置。之后修改协议内容时，应用只会请你重新阅读协议，不会重复整个向导。用户协议和使用指南也可以在「设置 → 关于」中随时查看。

用户协议共 14 节，涵盖：软件性质与许可证、不提供服务器或订阅、合法使用、数据只在本机、会连接哪些地方、VPN 与其他权限、导入配置的风险、服务分流与广告拦截的局限、可用性、第三方组件、责任限制、协议变更、反馈渠道和语言。协议以英文版为准，以应用内显示的版本为准。

进入「配置」，点右下角添加按钮，选择导入方式。导入完成后点选配置卡片，再到「代理」选择节点或策略组成员。返回首页，选择出站模式，轻点工牌连接。Android 会显示 VPN 授权窗口，确认后系统状态栏出现 VPN 标志，应用通知显示服务状态。

系统 VPN 授权与订阅导入是两项独立操作。导入只保存配置，不能代替系统授权。一般情况下，一次只能有一个应用占用 Android VPN 接口；启动另一个 VPN 应用时，系统可能断开当前服务。首次连接请确认选择的是实际代理节点，而不是订阅内用于展示到期时间或公告的占位节点。

## 2. 首页与连接操作

### 工牌开关

轻点工牌上的连接按钮即可建立或断开 VPN。工牌翻面跟随连接状态；长按后拖动只改变卡片姿态，不会切换节点或出站模式。松手后卡片按物理效果回摆。减少效果选项提供简化显示，方便偏好静态界面的用户。

切换到其他应用不会主动断开 VPN。返回 PingClash 后，请结合卡片状态、系统 VPN 设置及服务通知查看连接情况。最近任务卡片是应用窗口，前台通知代表服务，两者用途不同。需要停止代理时请使用连接按钮或通知中的停止操作。

### 规则、全局和直连

| 模式 | 使用方式 |
| --- | --- |
| 规则 | 根据当前配置中的规则及本地覆盖，选择对应的策略组和出站。适合日常分流。 |
| 全局 | 使用主代理选择处理流量。需要统一出站时使用。 |
| 直连 | 使用直连出站。它不会自动选择代理节点。 |

首页卡片顶部的滚轮用于切换模式。规则、全局、直连沿滚轮循环排列，中间的蓝色指针线下方是当前模式（加粗显示），两侧较淡的是相邻模式：

- **轻点左侧或右侧**：切换到那一侧的模式；连续轻点可连续切换。
- **左右拖动或轻甩**：滚轮随手指转动，松手后按惯性减速，停到最近的模式时稍微越过一点再回弹到位。转过每个模式时有轻微振动，到位时振动一下。
- 模式在滚轮到位时才切换，拖动过程中不会反复重载分流。开启「减少效果」后，滚轮直接移到相邻模式，不做惯性和回弹。

滚轮下方依次显示当前配置、节点、出口地区与网络，以及连接时的实时网速（未连接时显示订阅剩余流量）。点按这一区域可查看流量、时长、延迟和运行状态。切换配置请进入「配置」页；切换节点或策略组成员请进入「代理」页，避免把模式、配置和节点混为同一个选择。

### 网站连通性

首页卡片底部保留常用网站的紧凑检查项（竖屏时与模式卡片合为一张）。轻点单项测试该网站，闪电按钮测试当前显示的项目，展开按钮可选择更多目标。只有主动发起检查时才会产生对应测试流量，打开列表本身不会自动登录网站。

网站检查使用手机实际网络路径，判断当前网络能否访问该网站；它与节点 URL 测试不同。VPN 关闭时按当前网络访问，VPN 开启时按生效的模式和规则访问。只要网站在验证过的 HTTPS 连接上作出回应，就视为可访问并显示响应耗时，跳转到登录页、人机验证页或 403、429 等状态都属于此类；DNS 失败、超时、连接被拒绝或重置、证书异常视为不可访问。ChatGPT、Claude、Gemini 返回明确的地区不可用页面，或网站返回 451 时，标为访问受限。一次检查的结果不能代表账号登录或网站全部功能已经可用。

网络切换、连接状态或配置发生变化后，旧结果会更新或清理。遇到网页能打开而检查提示异常时，可重新检查并结合浏览器实际结果判断。不要为了某一次测试而关闭 HTTPS 证书验证。

### IP 信息

首页卡片的摘要中显示当前 IP 的国家/地区与所属网络。点按卡片打开详情，可查看 IP 地址、组织、ASN 和检测时间；连接 VPN 时还会显示当前规则为这次访问选择的线路（直连，或策略组、节点与协议）。

检测按手机当前的实际路径进行：VPN 开启时经过当前模式与规则，关闭时使用手机自身的网络，因此显示的是网站此刻看到的地址。连接或断开、切换模式、配置或主代理后会自动重新检测，也可在详情中点「刷新」。地址由 Cloudflare 返回，国家/地区之外的网络信息使用应用内置数据离线查询，结果只保存在内存中。

## 3. 添加和管理配置

### 导入入口

在「配置」页点右下角 **+**。展开菜单后，可以从 URL、剪贴板、粘贴的配置文本、文件、配置 ZIP 包、二维码图片或拍摄二维码开始。导入在一个页面中完成：填写内容，核对来源，点「下载并导入」；下载期间仍可返回取消。

- **URL**：粘贴 HTTPS 订阅地址，链接默认隐藏，下方显示将要下载的来源主机。名称可留空，按服务端提供的信息填写，也可以手动修改；User-Agent 位于「高级」中。
- **剪贴板**：读取你主动选择导入的内容，核对后再确认，不会因为复制了链接就自动下载或启用配置。
- **文本**：粘贴 Clash YAML、配置 JSON 或支持的节点 URI 列表。Base64 编码的订阅内容也可按导入格式处理。
- **文件**：使用 Android 系统文件选择器选择配置，无需向应用开放整个存储空间。
- **二维码**：从图片中离线解码，或调用系统相机获取二维码图像。请尽量使用清晰原图，避免反光和裁切。
- **ZIP 配置包**：适合包含本地 Provider 文件的配置，包内文件使用相对路径引用。

从网页打开 `clash://install-config?url=` 时，先核对来源主机并确认导入；导入之后再单独选择配置启用。链接中的配置名称只作为显示文本。来源地址应使用 HTTPS。任何带令牌的订阅链接都应按密码处理，不要贴到公开评论或截图里。

### ZIP 与提供源

配置包根目录使用一个 config.yaml、config.yml 或 config.json。其他文件按配置中的 Provider 相对路径放置，例如 providers/nodes.yaml。文件名和路径应准确对应，不要使用绝对路径或上级目录跳转。

Mihomo 配置可以包含 proxy-providers 与 rule-providers。应用读取配置中的来源与刷新信息，下载后保存在应用私有空间；策略组使用对应的成员，规则按原有顺序处理。支持的源形式、内容格式及覆盖由导入器与当前内核共同处理；规则源按内容识别格式，以 .txt 或 .list 发布的 YAML 列表也能正确读取。单个配置最多支持 5,000 个节点、512 个策略组和 50,000 条规则，订阅下载与导入内容最大 8 MiB；超出部分会跳过并在详情中计数。来源错误会在详情中按提供源序号定位，便于查找配置内容。

配置包含地理和 ASN 分类时，运行时使用相应的规则数据。保留配置内的组名、来源名称和引用关系，尤其不要只改组名而遗漏规则中的出站引用。对文件型提供源，应通过文件或 ZIP 导入相应内容。

### 配置卡片

所有配置纵向显示。点按整张卡片选择当前配置，高亮标记当前选择。卡片使用填充呈现剩余配额，支持流量变化与选中时的过渡效果。配额来自订阅服务的响应头；服务没有提供相关信息时，不会把未知数据当作无限流量。

卡片右上角菜单提供更新、重命名、复制订阅链接、显示详情、导出和删除等操作。详情中可查看使用量、总量、有效期、节点与策略组信息、来源状态及导入情况。复制后请注意系统剪贴板可能被其他应用读取；分享前确认内容确实适合对外公开。

### 更新、名称与 User-Agent

订阅更新重新获取来源内容，保留当前有效配置作为失败时的恢复依据。自动更新的间隔在「设置 → 自动化」中选择，默认每天一次。配置名可按自己的习惯重命名，不改变服务器账号。不同服务可能根据 User-Agent 返回不同格式，需要时在导入页或配置相关设置中填写服务商指定的值。User-Agent 只影响请求标识，不等于访问凭据。

流量配额与有效期由服务端的 subscription-userinfo 信息解析。总使用量通常由上传与下载相加得到，日期按设备时区显示。客户端的本地会话流量与服务商计费口径可能不同；订阅的计费、重置周期和续费以服务商为准。更新后可核对新的配额状态。

### 导出和删除

导出用于你自己保存或迁移配置。完整配置可能包含账号凭据、服务器信息和订阅链接，请存放在受保护的位置。脱敏诊断报告用于反馈问题，两者用途不同。不要把完整配置当作诊断报告发布。删除配置会移除应用中的记录；卸载或清除应用数据也会清除本地配置。

## 4. 代理、策略组与延迟

「代理」页沿用订阅中的组顺序、组名与成员关系。左右切换策略组，点按节点选择成员，嵌套策略组可继续进入。自动选择、故障转移等组按照其配置运行；组名不是节点协议，也不等于具体服务器地址。

右上角菜单可选择紧凑双列或单列布局，并使用名称或延迟相关的显示与排序操作。搜索用于查找当前配置的成员。协议名称作为副标题显示，长名称和较大字体会按布局调整。页面切换与诊断返回会保留可恢复的浏览状态。

### URL 延迟

闪电按钮发起由 Mihomo 执行的 URL 测试，比较经节点访问目标的耗时。节点测试可以在未启动本应用 VPN 时运行，因为它测试的是节点连接能力，不代表手机全部应用已由 VPN 接管。手机上已有其他 VPN 时，测试路径也可能包含该 VPN 的开销。

批量测试展开并去重组内节点，采用有界并行，逐步显示结果。再次点击运行中的图标可取消。批量测速期间可以选择其他节点。测速结果会保留：切换页面、离开应用、连接或断开 VPN 都不会清除已完成的结果；配置更新后，只有被删除或修改过的节点会清除结果，更改测速目标、超时或 DNS 时会全部清除。连接或断开 VPN 时，正在进行的测试会停止。网络情况、目标网站和首次握手都会影响数值，比较结果时尽量使用相同的目标与超时。

延迟颜色用于辅助识别：较低延迟显示绿色，中等延迟显示黄色，更高延迟或失败使用对应状态。数字表示本次测试，不是长期服务质量评分。没有结果、测试进行中、超时和有效延迟是不同状态，不会把失败填成一个看似成功的数值。

### TCP 与节点详情

长按节点打开详情，可单独测试 URL 延迟、验证 TCP 或诊断此节点。TCP 测试连接节点的主机和端口，反映入口可达性；URL 测试通过代理协议访问目标，反映更完整的路径。TCP 能连接不代表代理认证或目标网站一定成功。

UDP 协议的 TCP 指标显示不适用，不将其解释为失败。对自己的 VPN，入口辅助探测使用受保护的底层网络套接字，避免把代理入口再次绕进隧道。其他 VPN 正在工作时，部分直连辅助指标会受路径限制。某节点完成自己的 URL 测试后，即可继续查看该节点的诊断，不需要等全部列表结束。

## 5. 诊断、提醒和连接管理

### 连接诊断

从节点详情或设置进入诊断。结果按网络环境、入口 DNS、TCP、TLS 与代理通路等步骤展示。协议不使用的步骤会标记跳过。诊断不是自动扫描整个互联网，也不会为了判断故障而绕过证书验证。

查看结果时先找失败阶段：DNS 表示解析问题，TCP 表示入口连接问题，TLS 涉及证书、主机名与握手，代理通路还涉及协议认证和目标访问。超时、重置、拒绝连接和证书错误不是同一件事，单一错误不能证明网络受到攻击。可在同一设备上切换 Wi-Fi 与蜂窝后复测，比较结果。

诊断页底部的「手动检测域名或 IP」打开直连辅助检测：输入服务器域名或 IP、端口，可选 TLS 握手与 SNI，以及 IPv4 / IPv6。检测不经过节点，始终使用手机当前的物理网络（Wi-Fi 或蜂窝）；VPN 开启时同样绕过隧道。它只说明这台手机能否直接解析、连接到该地址，不说明代理是否可用。

### 提醒和警告

黄色提醒位于右上角，倒计时后自动收起。红色警告保留到滑动关闭或点开详情。详情展示阶段、固定原因与建议，避免在页面上长期堆放错误说明。导入失败时先查看来源或字段提示，不需要把完整订阅发给他人。

证书策略按配置处理。跳过验证时无法可靠确认服务器身份，应了解来源并检查服务商的证书设置。系统时间错误、SNI 不匹配和不受信任的证书都可能影响 TLS。普通错误信息可以截图；直接展示凭据的窗口采用单独的截图保护。

### 连接管理

进入「设置 → 连接管理」查看会话。VPN 未连接或暂时没有活动连接时，列表位置显示对应的状态卡片。启用相应显示后可查看目标、网络类型、命中规则类型、实际出站、连接时间和上下行流量。显示连接目标是独立选项，按需开启；这些内容可能涉及个人浏览行为，分享前应检查。

向左滑动连接行可露出删除操作，继续滑过阈值可以直接关闭该连接。这里的删除是关闭当前连接，不是删除节点或订阅。应用或网页仍在使用网络时，可能很快建立新连接。更换节点是否立即影响已有连接，也取决于连接和路由的实际状态。

### 分享报告

诊断报告在本机生成，分享前先预览，确认没有自己手动添加的敏感文本。反馈时通常只需应用版本、Android 版本、发生步骤、错误阶段和检查过的报告。不要提供账号密码、UUID、完整订阅地址或设备编号。崩溃报告同样由用户主动查看与分享，不自动上传。

## 6. DNS、分流与网络设置

### DNS

需要保留订阅本来的 DNS 行为时使用「配置中的 DNS」选项。手动配置时可选择应用提供的 DNS 模式及加密 DNS 地址。DNS over HTTPS 使用 HTTPS 地址，DNS over TCP 使用相应的服务器配置。修改前记录原值，避免同时更换节点、DNS 和规则而难以判断哪一步产生影响。

Fake-IP、域名规则与嗅探等行为依赖所用配置及内核运行方式。不要把 DNS 地址当作代理地址，也不要把 DNS 探测成功视为网站一定可达。若浏览器或系统自己启用了专用 DNS，也应结合其设置判断最终解析路径。

### 应用分流

「全部代理」让符合当前 VPN 路由的应用进入接口；「排除选中」将选中的应用排除；「仅代理选中」只允许选中的应用进入 VPN。列表支持搜索以及已选或系统应用筛选。勾选前确认应用名称和包名，系统组件应谨慎调整。

应用分流作用于 Android VPN 的应用范围，规则模式作用于进入核心后的出站决策。两者可以共同影响流量。改变需要重建系统 VPN 接口的设置时，按提示先断开再连接。使用锁定模式时，排除应用与系统阻断策略的组合也应单独确认。

### 出站规则和内网

保留订阅规则时可结合本地覆盖使用。规则中的类型、匹配内容、出站与规则源引用要对应，顺序影响匹配结果。填写规则后保存并查看检查结果，不要把运行规则序号误认为配置文件文本行号。

「设置 → 网络与连接」中的「内网」选项决定局域网流量的处理方式。需要访问路由器、打印机或 NAS 时，结合代理内网、内网直连与阻断内网的选择配置。不要在不了解用途时开放局域网监听。应用管理的控制接口使用受限的本地访问方式，不需要向其他设备公开控制端口。

### 服务分流

「设置 → 服务分流」按国家和地区列出常用服务，包括美国、英国、日本、韩国、中国 – 香港、中国 – 台湾、中国 – 大陆，以及 AI、游戏、工作与社交三个全球分类。每项服务可选：

| 选项 | 作用 |
| --- | --- |
| 代理 | 该服务走主代理（当前配置的主策略组或所选节点），也可以指定配置中的某个策略组。 |
| 直连 | 该服务不经过代理。 |
| 默认 | 不添加规则，由订阅自身的规则决定。 |

选择「代理」且当前配置含有策略组时，服务名下方会显示所走的代理，默认是「主代理」。点按它可以改为当前配置中的某个策略组，例如让 Netflix 走「日本」组。切换到没有该策略组的配置时，这项服务暂走主代理，并在名称下方说明；切回原配置后恢复。

这些选择属于 PingClash 自己，不属于某一个订阅：切换或更新订阅后仍然保留，也会随设置一起备份。它们在规则模式下生效，排在你的自定义规则之后、订阅规则之前；已连接时修改会立即生效，不需要断开。页面上方的广告拦截和国家/地区标签固定不动，只有下方的服务列表滚动；右上角的「清除全部选择」会把所有服务恢复为「默认」（不影响广告拦截）。

服务的域名来自应用内置的规则数据（GeoSite），不会从网络下载规则。一项服务包含在另一项里时（例如 YouTube 属于 Google），范围更小的服务优先，因此「Google 走代理、YouTube 直连」可以同时成立。选择「代理」只表示走主代理；能否观看某地区的内容，仍取决于你的节点所在地区和服务本身的限制。

### 广告拦截

「设置 → 服务分流」页面顶部的「广告拦截」可选「关闭」「广告」或「广告与跟踪」，依据应用内置规则数据拦截已知域名，在规则模式下生效。部分网站或应用可能因此无法正常使用，遇到时可在这里关闭。

### 连接参数

网络与连接页面提供自动重连、IPv6、UDP、MTU、连接超时、测速目标与并行数量等设置。大多数场景保持默认即可。MTU 影响包大小，过大或过小都可能改变实际体验；测速并行数过高也会增加手机与节点的瞬时负载。修改单项后再观察结果，便于对比。

## 7. 标准终端

终端是 Android `sh`，不是 Windows PowerShell，也不是完整 Linux 发行版。它运行在 PingClash 的应用 UID 与权限下，使用设备已有的命令、目录和网络。PTY 支持普通键盘、命令输出颜色、管道、重定向和交互式输入。

首次打开先阅读权限说明。点终端内容区域调出键盘，输入后回车执行。Ctrl+C 中断前台命令；退出 shell 使用 exit。终端内容可复制或截图，分享前检查命令及输出里有没有自己输入的订阅地址或口令。

下面的命令可直接用于查看环境，输出内容仍请自行检查：

```sh
pwd
id
uname -a
ls -la
printf '\033[36mPingClash terminal\033[0m\n'
printf 'one\ntwo\n' | wc -l
command -v ping
command -v curl
```

查看现有工具后，可使用设备支持的网络命令。下面以公开域名演示，不需要提供订阅凭据：

```sh
ping -c 3 example.com
```

某些 Android 系统未提供特定命令，或限制 ICMP、原始套接字和系统目录访问。command -v 可以确认命令是否存在。终端不会自动安装额外软件，也不会通过应用权限获得 Root。系统命令的请求遵循其实际路由，不等同于强制经某个所选节点。

不要执行不了解的远程脚本。终端有权限访问应用自己的文件，手动重定向也会留下文件；即使应用不保存持久命令历史，命令本身仍可能写入内容。避免在公共截图中展示环境变量、文件内容或带凭据的 URL。

## 8. 外观、后台与本地隐私

### 外观

在「语言与外观」选择简体中文、English、日本語或系统语言。可选择海洋与波浪、漂浮云朵、纯色背景或自己的图片，编辑预置色与自定义颜色。使用图片时，「填充」以双指缩放和拖动选取铺满屏幕的部分，「适应」完整显示所选部分并用图片边缘色或所选颜色填充其余区域；取色器提供网格、光谱和滑块三种方式。图片在本机重新编码保存，不保留原图元数据。深浅色模式按当前背景支持的选项提供。直接显示在背景上的标题和标签会随背景变色以保持清晰，包括自己的图片。减少效果与减少透明度用于按个人偏好简化动画和玻璃表现。

玻璃导航支持点选和拖动切换；长按工牌拖动与页面导航是不同交互。需要查看详细运行信息时打开首页详情面板，按显示选项决定速率、流量、服务和内存模块。状态通知中的网速显示可单独设置。

### 横屏与平板

横屏时底部导航变为左侧的毛玻璃侧边栏：展开时显示应用名称、各页面及连接状态，点左上角按钮可收起为图标栏，选择会被记住；平板默认展开，横握手机默认收起。平板竖屏时导航栏保持手机比例并居中，设置、配置等页面保持易读宽度，代理页按屏幕宽度显示更多列。

### 后台与重连

自动重连应对 Wi-Fi 与蜂窝网络切换。保持 VPN 常驻通知可见，并在系统中允许必要的通知权限；通知标题会显示当前模式。若系统电池管理限制后台服务，可在应用信息中调整电池优化和后台运行权限；不同厂商菜单名称可能不同。

Android 系统 VPN 设置中的「始终开启 VPN」负责持续启动服务，「阻止未经过 VPN 的连接」用于阻断隧道外连接。启用后先确认浏览器与常用应用正常工作，再决定是否长期使用。移除最近任务卡片与停止 VPN 服务不是同一个操作。

### 自动化与快捷方式

在下拉快捷设置中添加 PingClash 磁贴，或在桌面添加小组件，即可直接连接或断开；小组件同时显示当前网速。首次连接需要在应用内允许 VPN，之后磁贴和小组件无需打开应用。

「设置 → 自动化」提供：

- 开机时自动连接（默认关闭）。
- 订阅自动更新间隔：关闭、每 6/12 小时、每天（默认）、每 2/3 天或每周。有网络时在后台更新，仅使用 HTTPS；下载或校验失败时保留当前配置。
- 按网络自动连接（默认关闭）：在受信任的 Wi-Fi 下断开，在其他网络下连接，仅在网络切换时生效。Android 只在授予位置权限后提供 Wi-Fi 名称；应用关闭时也要生效，需要选择「始终允许」。

「设置 → 隐私与备份」中的备份把设置保存到你选择的文件。默认不含订阅链接、节点密码和用量；选择「包含配置」后文件含有凭据，请妥善保管。恢复会替换当前设置，并添加备份中尚未存在的配置，订阅会重新下载。

### 数据与分享

配置与偏好使用本机 Android Keystore 和 AES-GCM 加密保存，应用禁用系统云备份及迁移。没有广告、遥测和自动崩溃上报。订阅获取、提供源更新、DNS、测速与代理连接会访问你配置或主动选择的服务，这是对应功能的网络活动。

加密存储无法保护主动复制或导出的明文，也不能替代设备锁屏。更换设备前可在「隐私与备份」中备份；卸载、清除数据或系统密钥变化会影响本地数据恢复。不要把订阅、私钥或完整日志提交到公开仓库。

「关于」页面提供应用版本、Mihomo 版本及开源许可证。反馈问题时使用这些版本信息定位即可，不需要个人身份信息。软件功能与说明见本指南，项目及源码入口见 [README](../README.md)。
